# Integrated for Mac

[Download Integrated 1.0 for Mac (build 5)](https://github.com/joeorjosepht/Integrated-Release/releases/download/v1.0-5/Integrated-1.0-5.dmg)

Requires macOS 14 or later. Supports Apple silicon and Intel Macs.

Open the DMG and drag Integrated into Applications. Launch it from Applications, then pair it with Integrated on your iPhone for companion control from iPhone and Apple Watch.

[Release notes and checksums](https://github.com/joeorjosepht/Integrated-Release/releases/tag/v1.0-5)

This repository hosts public Mac downloads. The application source code is maintained separately.
